DESCRIPCIÓN

Sitio web responsive para el establecimiento Parrilla de Julián
(Cl. 17 # 18-28), que presenta su menú, promociones,
información institucional y datos de contacto.

TECNOLOGÍAS UTILIZADAS

- HTML5
- CSS3 (hoja de estilos externa)
- Bootstrap 5.3 (vía CDN)

ESTRUCTURA DEL PROYECTO
parrilla-de-julian/

- index.html        Página de inicio
- menu.html         Catálogo de productos
- promociones.html  Promociones activas
- nosotros.html     Sobre nosotros
- contacto.html     Contacto y formulario
- css/estilos.css   Estilos personalizados
- README.txt

INSTRUCCIONES

1. Descomprimir el archivo .zip
2. Abrir index.html en cualquier navegador
3. No requiere servidor ni instalación
4. Requiere conexión a internet (Bootstrap por CDN)
